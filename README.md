# Lucky Consultant Portfolio — Flat Upload Version

Versi ini sengaja dibuat tanpa folder `assets`, supaya semua file bisa langsung dipilih dan di-upload ke GitHub lewat browser.

## Cara upload
1. Ekstrak ZIP.
2. Buka repository GitHub.
3. Klik **Add file → Upload files**.
4. Di folder hasil ekstrak, tekan **Ctrl+A** lalu drag semua file ke area upload GitHub.
5. Klik **Commit changes**.
6. Buka **Settings → Pages** lalu pilih `Deploy from a branch`, branch `main`, folder `/ (root)`.

Pastikan `index.html` terlihat langsung di halaman utama repository.
